# DeepSeek 峰谷计价小组件（WinUI 3）v1.0.21.7 发布说明

- 版本：1.0.21.7
- 发布日期：2026-09-10
- 包名：DeepSeekPeak.Widget（独立于 PVE 小组件，配置互不干扰）

## 本次更新（1.0.21.7）

- 修复“重启（开机自启）后进程在、但桌面看不到窗口”的问题：
  - 根因一：自愈标记文件 `cloak-relaunch-flag` 残留后，旧逻辑会永久跳过遮盖自检，此后每次开机被 DWM 遮盖（cloaked）都无人自愈；
  - 根因二：旧的自愈重启走 `explorer shell:AppsFolder`，新窗口仍会被 DWM 再次遮盖；
  - 修复（对齐 PVE 小组件方案并增强）：遮盖自检改为窗口创建后即每 5 秒持续运行（不依赖 Activated 事件）；检测到被遮盖时改用包内 exe 直启自愈；自愈时间戳带 30 秒冷却，即使重启后仍被遮盖也会在冷却后再次自愈，直到窗口正常显示（避免死循环）；窗口恢复可见后自动清理标记。
  - 实测：启动即被遮盖（cloaked=2）→ 5 秒内自愈重启 → 新实例窗口正常可见。

## 历史更新（1.0.21.2）

- 新增 DeepSeek-V4-Flash-Vision-Exp 多模态模型价格：
  - 官方定价与 V4 Flash 完全一致，沿用峰谷计费（谷时命中输入 0.05 元 / 输入 1.5 元 / 输出 4.5 元每百万 tokens，峰时翻倍）；
  - 价格表新增「V4 Flash Vision」峰、谷两行，模型名自动换行，悬停可查看完整模型名。

## 历史更新（1.0.21.1）

- 修复“在不同缩放比例的屏幕之间拖动时窗口大小不改变”的问题：
  - 根因：低 DPI（如 100%）屏幕拖到高 DPI（如 150%）屏幕时，Windows 不会自动放大窗口物理尺寸，而 WinUI 的 Composition/布局系统又会用旧的逻辑视口尺寸覆盖窗口，导致窗口在高分屏上变小、内容挤在一起；
  - 修复：子类拦截 WM_DPICHANGED，跨屏瞬间按新 DPI 立即修正物理尺寸（保持逻辑 DIP 尺寸不变），并新增常驻 DPI 监视（每 500ms 检查一次），任何被 Composition 覆盖的错误尺寸都会在 500ms 内被纠正。

## 历史更新（1.0.21.0）

- 新增“每周规则”：周一～周日可分别设置是否全天按谷时，默认周六/周日全天谷（DeepSeek 官方 2026-08-23 起周末不再区分峰谷）。
- 修复时段图下方提示文字截断、跨天切换预告不显示日期、进入峰时进度条跳变的问题。

## 安装

- 一键安装：双击 `DeepSeek峰谷小组件-WinUI-安装程序.exe`，自动完成证书信任 + 安装/升级 + 启动（无需管理员，首次需系统允许旁加载）。
- 手动安装：解压 `DeepSeek峰谷小组件-WinUI-1.0.21.7-安装包(发给其他人).zip`，运行 `Add-AppDevPackage.ps1` 自动信任证书并安装。

## 功能

- 当前时段（峰时 · 全价 / 谷时 · 半价）、距下次切换倒计时 + 当前段进度条
- 24 小时峰谷时段图（当前时段颜色高亮 + 指示三角）
- 每周规则（周一～周日可分别设置全天谷时，默认周六/周日）
- 接下来 3 次切换节点预告（跨天显示星期）
- DeepSeek 账户余额卡片（拨轮码盘动画，刷新间隔可按秒配置）
- V4 Flash / V4 Pro / V4 Flash Vision 峰谷实时价格表（元 / 百万 tokens）
- 时段切换系统通知 + 提前 N 分钟提醒（默认提前 10 分钟）
- 简略版 / 完整版、置顶、图钉锁定、深色/浅色/跟随系统、亚克力背景、主题色
- 窗口位置记忆、多 DPI 屏幕自适应、定价自动刷新间隔、开机自启（StartupTask）

## 峰谷规则

官方公告（2026-08-23 起生效）：峰时为北京时间每天 09:00-12:00、14:00-18:00，其余 17 小时为谷时，谷时价格为峰时一半；周六、周日全天按谷价计费。
