# DeepSeek 峰谷计价小组件（WinUI 3）v1.0.23.0 发布说明

- 版本：1.0.23.0
- 发布日期：2026-10-26
- 包名：DeepSeekPeak.Widget（安装版）／DeepSeekPeakWidget.exe（绿色版）

## 本次更新（1.0.23.0）

- **法定节假日自动联网更新**：官方每年 11 月左右公布次年放假安排，小组件现在会自己联网取回最新日期，不再依赖内置清单。
  - 数据源：优先 `timor.tech`（国内可直连），失败自动切换 GitHub 上的 `holiday-cn` 开源数据（含国务院通知链接）；
  - 结果缓存在本地配置里，断网/接口不可用时继续使用内置清单（2026 年官方安排 + 2027 年法定节日核心日），不影响使用；
  - 启动时检查，超过 7 天才会重新拉取；设置里可关闭自动更新、点「立即更新」，并显示「上次更新：时间 · 来源」；
  - 鼠标悬停「24 小时时段图」下方的提示文字，可查看节假日数据的更新时间、来源与天数。
- **新增绿色版（免安装）**：解压即用，双击 `DeepSeekPeakWidget.exe` 运行。
  - 不需要安装、不需要管理员、不需要装证书，也不需要另外安装 .NET / Windows App SDK 运行库（已自带）；
  - 开机自启改为写入当前用户注册表 `Run` 项（安装版仍用商店式 StartupTask），右键菜单里同样一键开关；
  - 与安装版共用 `%LOCALAPPDATA%\DeepSeekPeakWidget\config.json`，卸载就是删文件夹。
- 其它：绿色版构建脚本 `installer\build-portable.ps1`（注意：必须用 MSIX 构建输出目录，`dotnet publish` 产物缺少 `resources.pri` 会无法启动）。
- 新增**独立证书一键安装脚本** `安装证书.cmd` / `Install-Cert.cmd`（配套 `Install-Cert.ps1`）：双击即把自签名证书 `CN=PVEWidget Dev` 装进当前用户的受信任根 / 受信任发布者 / 受信任人，并逐项打印校验结果；`-Remove` 卸载，`-MachineWide` 装进本机存储（管理员）。

## 安装 / 使用

- **免安装（推荐给不想安装的人）**：解压 `DeepSeekPeakWidget-portable-1.0.23.0-win-x64.zip`，双击 `DeepSeekPeakWidget.exe`。
- 一键安装（推荐发给别人）：双击 `DeepSeek峰谷小组件-WinUI-安装程序.exe`，自动完成证书信任 + 安装/升级 + 启动（无需管理员，首次需系统允许旁加载）。
- 一键脚本（装证书 + 装/升级 MSIX + 启动）：把 `DeepSeekWidget-Setup.cmd`（或中文名 `双击安装.cmd`）与 `.msix`、`.cer` 放在同一文件夹，双击即可；目录里没有安装包时会**自动从 GitHub 最新 Release 下载**再安装。
  - `-Offline` 关闭联网下载、`-Uninstall` 卸载、`-Reinstall` 同版本修复重装、`-NoLaunch` 装完不启动；
  - `-MachineWide` 把证书装进本机存储（需管理员，所有用户可用）；遇到证书/旁加载错误时脚本会自动提权重试。
- **只装证书（一键脚本）**：`安装证书.cmd`（或 `Install-Cert.cmd`）+ `pve-widget-cert.cer` 放同一文件夹，双击即把 `CN=PVEWidget Dev` 装进当前用户的受信任根 / 受信任发布者 / 受信任人并打印校验结果；`Install-Cert.ps1 -Remove` 可卸载，`-MachineWide`（需管理员）装进本机存储。
- 手动安装：解压 `DeepSeek峰谷小组件-WinUI-1.0.23.0-安装包(发给其他人).zip`，双击 `双击安装.cmd`。

## 功能

- 当前时段（峰时 · 全价 / 谷时 · 半价）、距下次切换倒计时 + 当前段进度条
- 24 小时峰谷时段图（当前时段颜色高亮 + 指示三角），悬停提示节假日数据来源
- 每周规则（周一～周日可分别设置全天谷时，默认周六/周日）＋法定节假日全天谷时（自动联网更新）
- 接下来 3 次切换节点预告（跨天显示星期）
- DeepSeek 账户余额卡片（拨轮码盘动画，刷新间隔可按秒配置）
- V4.1 Flash / V4 Pro 峰谷实时价格表（元 / 百万 tokens），附官方核对日期与搜索/抓取 API 计费提示
- 时段切换系统通知 + 提前 N 分钟提醒（默认提前 10 分钟）
- 简略版 / 完整版、置顶、图钉锁定、深色/浅色/跟随系统、亚克力背景、主题色
- 窗口位置记忆、多 DPI 屏幕自适应、开机自启（安装版 StartupTask / 绿色版注册表）、定价自动刷新间隔

## 峰谷规则

官方规则（以 2026-10-26 定价页为准）：

- 高峰时段：北京时间周一至周五（**不含中国法定节假日**）09:00-12:00、14:00-18:00，按全价计费；
- 空闲时段：其余时段（含周末与法定节假日全天），价格为高峰时段的一半；
- 调休上班的周六/周日仍按周末处理，全天谷时，无需特殊设置。

## 注意

- 需要 Windows 10/11 x64；亚克力模糊需系统“设置 → 个性化 → 颜色 → 透明效果”开启。
- 安装版配置写入 `%LOCALAPPDATA%\DeepSeekPeakWidget\config.json`（绿色版共用同一份）；含 `holidays`、`holidayAutoUpdate`、`holidayLastSync`、`priceRevision` 等字段。
- 节假日自动更新需要能访问 `timor.tech` 或 `raw.githubusercontent.com`；公司网络拦截时可在设置里关闭自动更新并手动编辑清单。
- 右键浮窗可打开菜单：立即刷新 / 切换简略版·完整版 / 个性化设置 / 编辑配置文件 / 重新加载配置 / 打开官方定价页面 / 开机自启 / 退出。
