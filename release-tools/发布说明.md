# DeepSeek 峰谷计价小组件（WinUI 3）v1.0.21.8 发布说明

- 版本：1.0.21.8
- 发布日期：2026-09-10
- 包名：DeepSeekPeak.Widget（独立于 PVE 小组件，配置互不干扰）

## 本次更新（1.0.21.8）

- 同步官方 flash 系列调价（北京时间 2026-09-10 12:00 起生效）：
  - 缓存命中输入 0.05 → **0.02** 元/百万 tokens（降幅 60%）；
  - 缓存未命中输入 1.50 → **1.00** 元（降幅 33.3%）；
  - 输出 4.50 → **4.00** 元（降幅 11.1%）；
  - 高峰时段为空闲时段 2 倍：**0.04 / 2.00 / 8.00** 元；
  - 对应模型随 V4.1 Flash 上线，价格表首行名称更新为「V4.1 Flash」（模型名 `deepseek-flash`）；V4 Flash Vision 属 flash 系列，同步按新价；V4 Pro 单价保持不变。
- 新增内置价格方案版本 `priceRevision`：官方调价后，旧配置文件中残留的旧单价会在启动时自动替换为新价并写回，无需手动删除或编辑 config.json。

> 若官方在 12:00 上线时对 flash 系列之外（如 Pro、Vision）另有调整，会在后续版本继续同步。

## 历史更新（1.0.21.7）

- 修复“重启（开机自启）后进程在、但桌面看不到窗口”的问题：
  - 根因一：自愈标记文件 `cloak-relaunch-flag` 残留后，旧逻辑会永久跳过遮盖自检，此后每次开机被 DWM 遮盖（cloaked）都无人自愈；
  - 根因二：旧的自愈重启走 `explorer shell:AppsFolder`，新窗口仍会被 DWM 再次遮盖；
  - 修复：遮盖自检改为窗口创建后即每 5 秒持续运行（不依赖 Activated 事件）；检测到被遮盖时改用包内 exe 直启自愈；自愈时间戳带 30 秒冷却，即使重启后仍被遮盖也会在冷却后再次自愈，直到窗口正常显示（避免死循环）；窗口恢复可见后自动清理标记。

## 历史更新（1.0.21.2）

- 新增 DeepSeek-V4-Flash-Vision-Exp 多模态模型价格行，模型名自动换行，悬停可查看完整模型名。

## 历史更新（1.0.21.1）

- 修复“在不同缩放比例的屏幕之间拖动时窗口大小不改变”的问题：子类拦截 WM_DPICHANGED，跨屏瞬间按新 DPI 修正物理尺寸，并新增每 500ms 的常驻 DPI 监视兜底。

## 历史更新（1.0.21.0）

- 新增“每周规则”：周一～周日可分别设置是否全天按谷时，默认周六/周日全天谷（DeepSeek 官方 2026-08-23 起周末不再区分峰谷）。
- 修复时段图下方提示文字截断、跨天切换预告不显示日期、进入峰时进度条跳变的问题。

## 安装

- 一键安装：双击 `DeepSeek峰谷小组件-WinUI-安装程序.exe`，自动完成证书信任 + 安装/升级 + 启动（无需管理员，首次需系统允许旁加载）。
- 手动安装：解压 `DeepSeek峰谷小组件-WinUI-1.0.21.8-安装包(发给其他人).zip`，运行 `Add-AppDevPackage.ps1` 自动信任证书并安装。

## 功能

- 当前时段（峰时 · 全价 / 谷时 · 半价）、距下次切换倒计时 + 当前段进度条
- 24 小时峰谷时段图（当前时段颜色高亮 + 指示三角）
- 每周规则（周一～周日可分别设置全天谷时，默认周六/周日）
- 接下来 3 次切换节点预告（跨天显示星期）
- DeepSeek 账户余额卡片（拨轮码盘动画，刷新间隔可按秒配置）
- V4.1 Flash / V4 Pro / V4 Flash Vision 峰谷实时价格表（元 / 百万 tokens）
- 时段切换系统通知 + 提前 N 分钟提醒（默认提前 10 分钟）
- 简略版 / 完整版、置顶、图钉锁定、深色/浅色/跟随系统、亚克力背景、主题色
- 窗口位置记忆、多 DPI 屏幕自适应、开机自启自愈、定价自动刷新间隔

## 峰谷规则

官方公告（2026-08-23 起生效）：峰时为北京时间周一至周五 09:00-12:00、14:00-18:00，其余为空闲（谷）时段，谷时价格为峰时一半；周六、周日全天按谷价计费。

## 注意

- 需要 Windows 10/11；亚克力模糊需系统“设置 → 个性化 → 颜色 → 透明效果”开启。
- 配置写入 %LOCALAPPDATA%\DeepSeekPeakWidget\config.json（含 weekValleyDays 每周规则、vision 价格、priceRevision 价格版本字段）。
- 右键浮窗可打开菜单：立即刷新 / 切换简略版·完整版 / 个性化设置 / 编辑配置文件 / 重新加载配置 / 打开官方定价页面 / 开机自启 / 退出。
