# DeepSeek 峰谷计价小组件（WinUI 3）1.0.12.0 发布说明

- 版本：1.0.12.0
- 发布日：2026-08-20
- 包名：`DeepSeekPeak.Widget`（独立于 PVE 小组件，配置互不干扰）

## 本次更新（1.0.12.0）

- 修复高分屏（150%/200% 缩放）下窗口尺寸缩水、内容被压缩错位的问题：
  `AppWindow.Resize` 使用物理像素，现已按显示器 DPI 缩放系数换算；窗口先定位到目标显示器再按该显示器 DPI 设置尺寸，监听跨屏拖动时的 DPI 变化，并在窗口显示后延迟校准一次。
- 默认不再置顶（`alwaysOnTop` 默认关闭）；如需置顶请在“个性化设置 → 窗口置顶”中开启。
- 修复“接下来切换”行内圆点与文字重叠、简略版状态卡文字重叠的问题：
  切换行改为「圆点 / 时间 / 剩余」三列布局，简略版缩小字号并隐藏次要行，长文本自动省略。
- 新增“背景透明度”自定义（对应 PVE 小组件的透明度设置，默认 0.97，可在“个性化设置 → 外观”中调整）。
- 背景透明度改为与 PVE 小组件一致：只调整亚克力背景 tint 颜色的 alpha（对应 PVE 渐变色的 alpha 通道），窗口内容保持不透明；深色主题 tint 固定为 PVE 同款 #141823，透明度越低背景越通透；背景效果为“无”时该设置不生效。
- 增强窗口位置记忆：关闭时记录显示器标识（PnP 设备 ID + 显示器名），启动时按“设备 ID → 显示器名 → 坐标”依次回退恢复到同一块屏幕。
- 新增定价自动刷新：可设置刷新间隔（分钟，默认 30，0=关闭），到点自动重读 config.json，价格或时段改动无需重启即生效；并修复重载配置后时段引擎不更新的问题。

## 功能

- 当前时段（峰时 · 全价 / 谷时 · 半价）+ 距下次切换倒计时 + 当前段进度条
- 24 小时峰谷时段图（当前小时高亮）
- 接下来 3 次切换节点预告
- V4 Flash / V4 Pro 峰谷实时价格表（元 / 百万 tokens）
- 时段切换系统通知 + 提前 N 分钟提醒（默认提前 10 分钟）
- 简略版 / 完整版、置顶、图钉锁定、深色/浅色/跟随系统、亚克力背景、5 套主题色
- 窗口位置记忆、开机自启（StartupTask）

## 峰谷规则

官方公告（2026-08-17 生效）：峰时为北京时间每天 09:00-12:00、14:00-18:00，其余 17 小时为谷时，谷时价格为峰时一半。

## 注意

- 需要 Windows 10/11；亚克力模糊需系统“设置 → 个性化 → 颜色 → 透明效果”开启。
- 配置写入 `%LOCALAPPDATA%\DeepSeekPeakWidget\config.json`。
- 右键浮窗可打开菜单：立即刷新 / 切换简略版·完整版 / 个性化设置 / 编辑配置文件 / 重新加载配置 / 打开官方定价页面 / 开机自启 / 退出。
