# DeepSeek 峰谷计价小组件（WinUI 3）v1.0.22.0 发布说明

- 版本：1.0.22.0
- 发布日期：2026-10-26
- 包名：DeepSeekPeak.Widget（独立于 PVE 小组件，配置互不干扰）

## 本次更新（1.0.22.0）

- 按官方定价页（2026-10-26 核对）校对价格：`deepseek-flash`（DeepSeek-V4.1-Flash-1017）空闲 0.02 / 1.00 / 4.00、高峰 0.04 / 2.00 / 8.00 元每百万 tokens；`deepseek-v4-pro`（DeepSeek-V4-Pro-0813）空闲 0.15 / 4.50 / 13.50、高峰 0.30 / 9.00 / 27.00。与 1.0.21.8 预置价格一致，本次**无需改价**。
- 价格表按官方现状整理为 2 个模型 × 谷/峰共 4 行：
  - 移除已下线的「V4 Flash Vision」独立行（官方脚注：旧模型名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 仍可调用但对应模型已下线，请求由 DeepSeek-V4.1-Flash-1017 提供服务并按 Flash 计费；图像理解现由 `deepseek-flash` 支持）；
  - 模型名悬停可查看官方模型名与版本号。
- 新增「法定节假日全天谷时」规则：官方规则为北京时间周一至周五（不含中国法定节假日）09:00-12:00、14:00-18:00 为高峰时段，其余时段——包括周末与法定节假日全天——均为空闲时段。
  - 设置窗口新增节假日清单编辑（每行一个 `yyyy-MM-dd`），并附「恢复内置节假日清单」按钮；
  - 内置 2026 年国务院办公厅放假安排（国办发明电〔2025〕7 号）与 2027 年法定节日核心日（2027 年完整放假/调休安排预计 2026 年 11 月公布，届时可在此补充）；
  - 当天为法定节假日时，状态卡显示「今日法定节假日 · 全天按谷时（半价）计费」，时段提示中也会注明。
- 价格卡片新增「网页搜索 / 抓取 API」计费提示：官方宣布自北京时间 2026-11-01 00:00 起，Search / Fetch 按 5 元 / 千次成功请求计费（此前在 Harness / Claude Code / Codex 中的服务端调用暂不计费）；卡片会显示距离开始计费的天数。
- 修复 `tools/capture-deepseek-pricing.ps1` 定价抓取脚本：官方价格页已改为 2 个模型、每档 2 个报价，旧正则无法匹配；现按「模型名 + 每档连续报价」动态解析，输出模型版本号，并分别与程序内 flash / pro 基线比对。
- 配置迁移：`priceRevision` 升级为 `2026-10-26`；旧配置缺少 `holidays` 字段时自动补齐内置清单，已有自定义设置不受影响。

## 历史更新（1.0.21.8）

## 安装

- 一键安装：双击 `DeepSeek峰谷小组件-WinUI-安装程序.exe`，自动完成证书信任 + 安装/升级 + 启动（无需管理员，首次需系统允许旁加载）。
- 手动安装：解压 `DeepSeek峰谷小组件-WinUI-1.0.22.0-安装包(发给其他人).zip`，运行 `Add-AppDevPackage.ps1` 自动信任证书并安装。

## 功能

- 当前时段（峰时 · 全价 / 谷时 · 半价）、距下次切换倒计时 + 当前段进度条
- 24 小时峰谷时段图（当前时段颜色高亮 + 指示三角）
- 每周规则（周一～周日可分别设置全天谷时，默认周六/周日）＋法定节假日全天谷时
- 接下来 3 次切换节点预告（跨天显示星期）
- DeepSeek 账户余额卡片（拨轮码盘动画，刷新间隔可按秒配置）
- V4.1 Flash / V4 Pro 峰谷实时价格表（元 / 百万 tokens），附官方核对日期与搜索/抓取 API 计费提示
- 时段切换系统通知 + 提前 N 分钟提醒（默认提前 10 分钟）
- 简略版 / 完整版、置顶、图钉锁定、深色/浅色/跟随系统、亚克力背景、主题色
- 窗口位置记忆、多 DPI 屏幕自适应、开机自启自愈、定价自动刷新间隔

## 峰谷规则

官方规则（以 2026-10-26 定价页为准）：

- 高峰时段：北京时间周一至周五（**不含中国法定节假日**）09:00-12:00、14:00-18:00，按全价计费；
- 空闲时段：其余时段（含周末与法定节假日全天），价格为高峰时段的一半；
- 调休上班的周六/周日仍按周末处理，全天谷时，无需特殊设置。

## 注意

- 需要 Windows 10/11；亚克力模糊需系统“设置 → 个性化 → 颜色 → 透明效果”开启。
- 配置写入 %LOCALAPPDATA%\DeepSeekPeakWidget\config.json（含 weekValleyDays 每周规则、holidays 法定节假日、priceRevision 价格版本字段）。
- 2027 年法定节假日目前仅内置“法定节日核心日”；国务院公布 2027 年放假安排后，可在设置中补充调休放假日期。
- 右键浮窗可打开菜单：立即刷新 / 切换简略版·完整版 / 个性化设置 / 编辑配置文件 / 重新加载配置 / 打开官方定价页面 / 开机自启 / 退出。
